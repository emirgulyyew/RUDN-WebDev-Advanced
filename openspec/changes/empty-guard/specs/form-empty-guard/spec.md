## Purpose

Защита формы `NewCardForm` от отправки карточки с пустым или состоящим только из пробелов названием.

## ADDED Requirements

### Requirement: Поле ввода обрезает пробелы

При валидации значения поля ввода система должна обрезать ведущие и завершающие пробелы перед проверкой на пустоту.

#### Scenario: Обрезка пробелов

- **WHEN** пользователь вводит значение `"  Моя карточка  "`
- **THEN** при валидации используется значение `"Моя карточка"`

#### Scenario: Пробелы только в начале

- **WHEN** пользователь вводит значение `"   "`
- **THEN** после обрезки получается пустая строка `""`

### Requirement: Кнопка отправки отключена для пустого поля

Кнопка «Добавить» должна иметь атрибут `disabled`, если значение поля после обрезки пробелов пусто.

#### Scenario: Кнопка отключена при пустом поле

- **WHEN** поле ввода пустое или содержит только пробелы
- **THEN** кнопка «Добавить» имеет атрибут `disabled` и неактивна

#### Scenario: Кнопка активна при заполненном поле

- **WHEN** поле ввода содержит непустой текст (после обрезки пробелов)
- **THEN** кнопка «Добавить» активна и может быть нажата

### Requirement: Визуальная обратная связь при попытке отправки пустой формы

Если пользователь пытается отправить форму с пустым полем (например, нажав Enter), система должна показать визуальную подсказку об ошибке.

#### Scenario: Подсветка поля красным

- **WHEN** пользователь пытается отправить форму с пустым полем
- **THEN** поле ввода подсвечивается красной рамкой

#### Scenario: Текст подсказки об ошибке

- **WHEN** пользователь пытается отправить форму с пустым полем
- **THEN** под полем ввода отображается текст «Введите название карточки»

#### Scenario: Скрытие ошибки после ввода

- **WHEN** пользователь вводит текст в поле после показа ошибки
- **THEN** красная подсветка и текст ошибки скрываются
