## Purpose

Отображение счётчика карточек в шапке доски, показывающего количество выполненных и общее число карточек, с корректной обработкой состояний загрузки и ошибок.

## ADDED Requirements

### Requirement: Счётчик отображает количество карточек

Система SHALL отображать в `BoardHeader` счётчик карточек в формате `выполненные / всего`.

#### Scenario: Счётчик показывает корректное количество

- **WHEN** в доске есть 4 карточки, из которых 1 выполнена
- **THEN** в шапке отображается `1 / 4`

#### Scenario: Счётчик показывает 0 карточек

- **WHEN** в доске нет карточек
- **THEN** в шапке отображается `0 / 0`

#### Scenario: Счётчик обновляется при изменении карточек

- **WHEN** карточка помечена как выполненная или создана новая карточка
- **THEN** счётчик автоматически обновляется с новым значением

### Requirement: Обработка состояния загрузки

Система SHALL отображать индикатор загрузки, пока данные о карточках не получены.

#### Scenario: Показ индикатора загрузки

- **WHEN** данные о карточках ещё загружаются (запрос в процессе)
- **THEN** отображается текст «Загрузка...» вместо числового счётчика

#### Scenario: Скрытие индикатора после загрузки

- **WHEN** данные о карточках успешно загружены
- **THEN** индикатор загрузки скрывается и показывается числовой счётчик

### Requirement: Обработка ошибки загрузки

Система SHALL отображать сообщение об ошибке при неудачной загрузке карточек.

#### Scenario: Показ сообщения об ошибке

- **WHEN** загрузка карточек завершилась с ошибкой (сетевая ошибка, сервер недоступен)
- **THEN** отображается сообщение «Ошибка загрузки» вместо числового счётчика

#### Scenario: Скрытие ошибки при повторной успешной загрузке

- **WHEN** после ошибки произошла повторная успешная загрузка карточек
- **THEN** сообщение об ошибке скрывается и показывается числовой счётчик
