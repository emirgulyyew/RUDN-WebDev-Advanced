## Why

На доске нет визуальной индикации количества карточек, что затрудняет быструю оценку текущего состояния задачи. Пользователь не видит, сколько карточек создано, сколько из них выполнено, без подсчёта вручную. Добавление счётчика в шапку доски решит эту проблему.

## What Changes

- Добавить компонент счётчика карточек в `BoardHeader`, отображающий количество карточек в формате `выполненные / всего` (например, `1 / 4`).
- Счётчик получает данные через props из `App.tsx` (текущий уровень — хардкод-массив карточек).
- Обработка граничных случаев:
  - **0 карточек всего**: отображается `0 / 0` или сообщение «Нет карточек».
  - **Загрузка данных**: показывается индикатор загрузки (спиннер или текст «Загрузка...»).
  - **Ошибка загрузки**: отображается сообщение об ошибке (например, «Ошибка загрузки»).
- Счётчик стилизован через CSS Modules (`BoardHeader.module.css`).

## Capabilities

### New Capabilities
- `board-card-counter`: Отображение счётчика карточек в шапке доски в формате `выполненные / всего` с обработкой состояний загрузки и ошибки.

### Modified Capabilities
- *(нет)*

## Impact

- `client/src/components/BoardHeader/BoardHeader.tsx` — добавление пропсов для карточек и рендеринга счётчика.
- `client/src/components/BoardHeader/BoardHeader.module.css` — стили для счётчика.
- `client/src/App.tsx` — передача массива карточек в `BoardHeader`.
- Никаких изменений на бэкенде не требуется.
