## Purpose

Возможность удаления карточек из доски через кнопку удаления с подтверждением, состоянием загрузки и обработкой ошибок.

## ADDED Requirements

### Requirement: Кнопка удаления отображается в карточке

Компонент `BoardCard` SHALL отображать кнопку удаления, видимую при наведении на карточку.

#### Scenario: Кнопка удаления отображается при наведении

- **WHEN** пользователь наводит курсор на карточку
- **THEN** в правом верхнем углу карточки появляется кнопка удаления (иконка "x")

#### Scenario: Кнопка удаления скрыта по умолчанию

- **WHEN** курсор не наведён на карточку
- **THEN** кнопка удаления не видна

### Requirement: Подтверждение удаления

Система SHALL запрашивать подтверждение перед удалением карточки.

#### Scenario: Пользователь подтверждает удаление

- **WHEN** пользователь нажимает кнопку удаления и подтверждает действие в модальном окне / `confirm()`
- **THEN** карточка отправляется на удаление на сервер

#### Scenario: Пользователь отменяет удаление

- **WHEN** пользователь нажимает кнопку удаления и отменяет действие в модальном окне / `confirm()`
- **THEN** карточка не удаляется, никаких запросов на сервер не отправляется

### Requirement: Состояние загрузки при удалении

Система SHALL отображать состояние загрузки во время отправки запроса на удаление.

#### Scenario: Кнопка блокируется при удалении

- **WHEN** пользователь подтвердил удаление
- **THEN** кнопка удаления блокируется (disabled) и показывает спиннер вместо иконки "x"

#### Scenario: Кнопка разблокируется после завершения удаления

- **WHEN** запрос на удаление завершён (успешно или с ошибкой)
- **THEN** кнопка удаления разблокируется и возвращает исходное состояние

### Requirement: Обновление списка карточек после удаления

Система SHALL обновлять локальный список карточек после успешного удаления.

#### Scenario: Карточка исчезает из UI после удаления

- **WHEN** сервер вернул успешный ответ (204) на удаление карточки
- **THEN** карточка удаляется из локального состояния и исчезает из UI

#### Scenario: Карточка остаётся при ошибке удаления

- **WHEN** сервер вернул ошибку (404 или другая)
- **THEN** карточка остаётся на месте, отображается сообщение об ошибке

### Requirement: Обработка ошибки удаления

Система SHALL отображать сообщение об ошибке при неудачном удалении карточки.

#### Scenario: Ошибка сети при удалении

- **WHEN** запрос на удаление завершился сетевой ошибкой
- **THEN** отображается сообщение «Не удалось удалить карточку»

#### Scenario: Карточка не найдена на сервере

- **WHEN** сервер вернул статус 404
- **THEN** отображается сообщение «Карточка не найдена»
