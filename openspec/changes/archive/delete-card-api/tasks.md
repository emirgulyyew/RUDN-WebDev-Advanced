# Tasks: Удаление карточки (KAN-3)

## Задача 1 — Маршрут `DELETE /cards/:id`

**Файл:** `server/index.ts`
**Расположение:** после маршрута `POST /cards`, перед `app.listen`

**Действия:**

1. Зарегистрировать `app.delete('/cards/:id', ...)`
2. В обработчике извлечь `const id = req.params.id;`
3. Найти индекс карточки через `cards.findIndex(c => c.id === id)`
4. Если индекс `=== -1` — вернуть `res.status(404).json({ error: 'Карточка не найдена' })` и завершить обработчик
5. Если карточка найдена — вызвать `cards.splice(index, 1)` для удаления
6. Вернуть `res.status(200).json({ message: 'Карточка удалена', id })`

**Критерий выполнения:** запрос `DELETE /cards/<существующий_id>` возвращает 200 с удалённой карточкой в ответе; запрос с несуществующим id возвращает 404 JSON.

## Задача 2 — Обработчик неизвестных путей (404 JSON)

**Файл:** `server/index.ts`
**Расположение:** после всех маршрутов (`GET`, `POST`, `DELETE`), перед `app.listen`

**Действия:**

1. Зарегистрировать `app.use((req, res) => { ... })`
2. В обработчике вернуть `res.status(404).json({ error: 'Маршрут не найден' })`
3. Убедиться, что обработчик размещён после всех `app.get`, `app.post`, `app.delete`

**Критерий выполнения:** запрос к любому несуществующему маршруту (например `GET /unknown`) возвращает 404 JSON.

## Задача 3 — Глобальный обработчик ошибок (500 JSON)

**Файл:** `server/index.ts`
**Расположение:** после обработчика 404, перед `app.listen`

**Действия:**

1. Зарегистрировать `app.use((err, req, res, next) => { ... })` — мидлвар с **четырьмя** параметрами
2. В обработчике вернуть `res.status(500).json({ error: 'Внутренняя ошибка сервера' })`
3. Убедиться, что мидлвар имеет ровно 4 параметра (Express использует это для распознавания как обработчика ошибок)

**Критерий выполнения:** при возникновении необработанного исключения в любом обработчике возвращается 500 JSON.
