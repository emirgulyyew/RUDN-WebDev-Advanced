# Spec Delta: Удаление карточки (KAN-3)

## 1. Модифицируемые компоненты

| Компонент     | Тип   | Описание                         |
| ------------- | ----- | -------------------------------- |
| `server/index.ts` | файл | Сервер Express, маршрутизация и обработчики |

## 2. Изменения в `server/index.ts`

### 2.1 Маршрут `DELETE /cards/:id`

- **HTTP-метод:** `DELETE`
- **Путь:** `/cards/:id`
- **Параметр маршрута:** `id` (строка, из `req.params.id`)

**Поведение:**

1. Найти карточку в массиве `cards`, у которой `id` равен `req.params.id`.
2. **Если карточка не найдена:**
   - Статус: `404`
   - Тело ответа (JSON): `{ "error": "Карточка не найдена" }`
   - Заголовок `Content-Type`: `application/json`
3. **Если карточка найдена:**
   - Удалить карточку из массива `cards`.
   - Статус: `200`
   - Тело ответа (JSON): `{ "message": "Карточка удалена", "id": "<удалённый id>" }`
   - Заголовок `Content-Type`: `application/json`

### 2.2 Обработчик неизвестных путей (404 JSON)

- Применяется как финальный маршрут **после** всех определённых маршрутов (`app.get`, `app.post`, `app.delete` и т.д.).
- Для любого HTTP-метода и любого пути, не совпавшего с ранее определёнными маршрутами:
  - Статус: `404`
  - Тело ответа (JSON): `{ "error": "Маршрут не найден" }`
  - Заголовок `Content-Type`: `application/json`

### 2.3 Глобальный обработчик ошибок (500 JSON)

- Express-мидлвар с **четырьмя** параметрами: `(err, req, res, next)`.
- Размещается **после** всех маршрутов и обработчика 404.
- При возникновении необработанного исключения в любом обработчике:
  - Статус: `500`
  - Тело ответа (JSON): `{ "error": "Внутренняя ошибка сервера" }`
  - Заголовок `Content-Type`: `application/json`

## 3. Неизменяемые компоненты

- Тип `Card` и его поля (`id`, `title`, `isDone`, `isUrgent?`) — без изменений.
- Массив `cards` — структура хранения без изменений (удаление элемента допустимо).
- Существующие маршруты `GET /cards` и `POST /cards` — без изменений.
- Мидлвар `express.json()` — без изменений.

## 4. Примеры

### 4.1 Успешное удаление

```http
DELETE /cards/1
```

Ответ:

```json
{
  "message": "Карточка удалена",
  "id": "1"
}
```

Статус: `200`

### 4.2 Карточка не найдена

```http
DELETE /cards/999
```

Ответ:

```json
{
  "error": "Карточка не найдена"
}
```

Статус: `404`

### 4.3 Неизвестный маршрут

```http
GET /unknown
```

Ответ:

```json
{
  "error": "Маршрут не найден"
}
```

Статус: `404`

### 4.4 Внутренняя ошибка сервера

При непредвиденном исключении:

Ответ:

```json
{
  "error": "Внутренняя ошибка сервера"
}
```

Статус: `500`
