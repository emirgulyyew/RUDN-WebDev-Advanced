# Proposal: Удаление карточки (KAN-3)

## Контекст

В текущей реализации сервера доступны только два эндпоинта для работы с карточками:
- `GET /cards` — получение списка всех карточек
- `POST /cards` — создание новой карточки

Отсутствует возможность удаления карточки, что не позволяет реализовать полный CRUD-цикл.

## Цель

Добавить серверный эндпоинт для удаления карточки по ID, а также обработчики для случаев, когда карточка не найдена, запрошен неизвестный маршрут или возникла внутренняя ошибка сервера.

## Изменения

### Сервер (`server/index.ts`)

1. **Маршрут `DELETE /cards/:id`**
   - Извлекает `id` из параметров маршрута (`req.params.id`).
   - Ищет карточку с таким `id` в массиве `cards`.
   - Если карточка не найдена — возвращает **404** с JSON: `{ "error": "Карточка не найдена" }`.
   - Если карточка найдена — удаляет её из массива и возвращает **200** с JSON: `{ "message": "Карточка удалена", "id": "<удалённый id>" }`.

2. **Обработчик неизвестных путей (404 JSON)**
   - Для всех маршрутов, не совпавших ни с одним определённым `app.METHOD`, возвращает **404** с JSON: `{ "error": "Маршрут не найден" }`.

3. **Глобальный обработчик ошибок (500 JSON)**
   - Express-мидлвар с 4 параметрами `(err, req, res, next)` улавливает необработанные исключения.
   - Возвращает **500** с JSON: `{ "error": "Внутренняя ошибка сервера" }`.
